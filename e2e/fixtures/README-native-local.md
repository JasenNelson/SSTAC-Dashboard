# v0.9.91 native figure route E2E

The governed launcher invokes `run-native-local-e2e.cjs` with `--config` and `--config-sha256`. The config is an absolute JSON file under this checkout's ignored `.tmp/native-local-e2e` directory. It supplies this checkout root, the private corpus root, the candidate manifest path and hash, and one to four permitted input roots. An optional evidence root must be under an explicit permitted output root; otherwise evidence goes under this checkout's `.tmp/native-local-e2e/R9`. Missing, malformed, escaped, or credential-bearing inputs fail before local services or auth start.

The launcher validates the three-object manifest hash and all private source bytes before starting a localhost Supabase fixture proxy, an inner Next dev server, and the focused Chromium spec. It prints readiness, periodic heartbeat, result, and cleanup markers. Raw child output is suppressed because failure diagnostics may contain private source text. The launcher proves both child processes exited, the proxy closed, and both ports are free before reporting cleanup completion. Ports 32631 and 32632 must be free. The child environment uses synthetic loopback settings and excludes ambient provider credentials. The native runtime tests cover input portability, rejection, monitoring, and cleanup.
