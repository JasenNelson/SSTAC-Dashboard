# Guide: Matrix Options Workspace

This workspace supports the 2026-2027 Matrix Sediment Standards Derivation Options Analysis for British Columbia (Phase 2). It provides the core review surfaces for the scientific framework, modernized Schedule 3.4 structure, and Technical Working Group collaborative review, alongside tools (Database, Calculator, SSD Workbench, Catalogue) currently under development in Phase 2 in preparation for Phase 3 standards development.

Use the Phase 2 review surfaces to evaluate derivation options, explore pathway frameworks, and record feedback on the draft Matrix Options Paper. Calculator outputs are screening-level prototypes, not final sediment standards.

## 1. How to Use This Workspace

Use the top tabs to move between the main review surfaces:

*   **Phase 2 Scope (2026-2027):**
    *   **Guide:** Gives project context, workflow, and key terms.
    *   **Modernizing Schedule 3.4:** Sets out the three-part structure of the modernized Schedule 3.4 and the four receptor-pathways of the Part 1 Matrix standards.
    *   **TWG Review:** The working draft Matrix Options Paper, supporting inline commentary and Technical Working Group review.
*   **Phase 3 Scope (under development):**
    *   **Database:** Geospatial map and interactive querying of provincial sediment quality data.
    *   **Calculator:** Interactive screening-level standard derivations across ecological and human health pathways.
    *   **SSD Workbench:** Species Sensitivity Distribution modeling for deriving protective hazardous concentration ($HC_p$) thresholds from ecotoxicological test data.
    *   **Catalogue:** Comprehensive evidence library of regulatory sources, toxicity reference values (RfDs, slope factors), equations, and audited parameter provenance.

A typical review flow is: read the **Guide**, review the vision and approach for **Modernizing Schedule 3.4**, and then contribute to the collaborative development of the draft Matrix Options paper in **TWG Review**.

## 2. Project Roadmap

The sediment standards modernization work is moving through three broad phases:

*   **Phase 1 (2025): Scientific Framework Development**
    *   Included a Scientific Literature Search and Jurisdictional Scan.
    *   Collaboratively developed the scientific framework for developing modern sediment standards.
    *   Multi-faceted engagement informed the strategic phased approach currently underway.
*   **Phase 2 (2026-2027): Foundational Research and Framework Development**
    *   Supports the Matrix Sediment Standards Derivation Options Analysis.
    *   Supports development of a scientific model for bioavailability adjustment, such as the Bayesian Network Relative Risk Model.
    *   Dashboard tabs Database, Calculator, SSD Workbench, and Catalogue are under development in preparation for Phase 3.
*   **Phase 3 (2028+): Staged Development of Sediment Standards**
    *   Utilize framework to derive new numerical standards for substances on a prioritized basis.
    *   Continues research and database development needed to support defensible standards over time.
