# AGY Executor Profile Generator, Stream Receipt Validator & Autonomous Worker Controller

Tooling for generating fail-closed Antigravity (AGY) executor profiles, executing tracked foreground worker sessions, and validating stream receipts for SSTAC-Dashboard.

> [!IMPORTANT]
> **Version Scope**: This tooling applies strictly to **Antigravity CLI 1.1.8**.
> A re-probe and re-verification of settings schema, model slug, stream receipt structure, denial behavior, and tool names is **mandatory** after any AGY CLI version update. Global AGY settings (`~/.gemini`) remain untouched and are not endorsed.

---

## Architecture & Security Posture

### 1. Containment Model
- **Isolated User Profiles**: AGY runs with an isolated per-run `USERPROFILE` directory generated by `New-AgyExecutorProfile.ps1`.
- **Dedicated Worktrees**: AGY must operate inside a dedicated, isolated git worktree, never the primary checkout (`C:\Projects\SSTAC-Dashboard`).
- **Global Profile Protection**: The user's global AGY profile (`~/.gemini`) is never inspected, copied, or modified.
- **Headless Auto-Denial**: In headless execution mode, the default `request-review` posture auto-denies any permission string not explicitly present in `permissions.allow`.
- **Workspace Read & Writable Scopes**: `read_file(<WorkspaceRoot>)` is explicitly required and automatically added to `permissions.allow` because AGY auto-denies unlisted read calls in headless mode. Explicit `WritablePaths` are required to grant `write_file(<path>)` permissions.
- **Mandatory Protected Paths**: Existing paths from the mandatory SSTAC set and all existing immediate children of `WorkspaceRoot` matching `.env*` are automatically added to `permissions.deny` even when caller `ProtectedPaths` is empty:
  - **Read and Write Deny**: `.git`, all existing immediate root items matching `.env*` (e.g. `.env`, `.env.local`, `.env.test`, `.env.production.local`), `node_modules`, `src/data`, `supabase/migrations`.
  - **Write Deny Only**: `AGENTS.md`, `CLAUDE.md`, `.agents`, `.claude`, `.codex`, `.gemini`, `.mcp.json`, `opencode.json`, `package.json`, `package-lock.json`.
  - Mandatory protected paths and their modes (`read_write` or `write_only`) are recorded in `PROFILE_MANIFEST.json`.
- **Denied Roots Authority**: Receipt validation checks target paths against explicit `deniedReadRoots` and `deniedWriteRoots`. Any target path equal to or descending from a denied root yields `READ_PATH_DENIED` or `WRITE_PATH_DENIED` regardless of any broader workspace allow. Production invocations derive these exact roots directly from `PROFILE_MANIFEST.json` (`protected_paths` plus `mandatory_protected_paths` matching mode `read_write` or `write_only`).
- **Reparse-Point Traversal Defense**: Syntactic path resolution is insufficient. For each `WritablePath`, `WorkspaceRoot`, `ProfileRoot`, `PromptFile`, `AgyExecutable`, `NodeExecutable`, and `validate-agy-stream.mjs`, every existing path component from the filesystem root is walked to reject `ReparsePoint` attributes (junctions/symlinks).
- **Exact Command Authority vs. OS Containment**: Exact command rules reduce accidental authority, but they do **not** constitute OS-level containment. Receipt validation is receipt verification, not OS-level process isolation.

### 2. Live-Canary Evidence & Corrections (AGY 1.1.8)
- **Version Status**: AGY 1.1.8 canaries are classified as historical local evidence. AGY 1.1.9 is unvalidated in this lane.
- **Live-Canary Receipt Verification**:
  1. Protected `.env` read: Auto-denied natively without owner prompt. Stream receipt classified as `RED` with `READ_PATH_DENIED` and `TOOL_ERROR`.
  2. Protected sibling write: Auto-denied natively without owner prompt. Stream receipt classified as `RED` with `WRITE_PATH_DENIED` and `TOOL_ERROR`.
  3. Unlisted command: Auto-denied natively without owner prompt. Stream receipt classified as `RED` with `UNAPPROVED_COMMAND` and `TOOL_ERROR`.
  4. Exact allowed command plus exact source edit: Executed successfully in canary run, printing `CANARY_TEST_PASS`. Validator classifies as `GREEN`.
- **Correction Rounds 4 and 5 Receipt Finding**: Correction rounds had native exit 0 and terminal `SUCCESS`, but contained tool `ERROR` lifecycles or uncaptured stdout streams. They are classified as acceptance-`RED` with `TOOL_ERROR`. Terminal `SUCCESS` cannot self-certify a run.
- **AGY 1.1.8 Settings Key Deprecation (2026-07-30 Observation)**: Antigravity CLI 1.1.8 was observed on 2026-07-30 removing `allowNonWorkspaceAccess` from isolated settings at startup. The generator (`New-AgyExecutorProfile.ps1`) therefore does not emit or rely on `allowNonWorkspaceAccess`. Fail-closed boundary enforcement relies strictly on explicit permission allow/deny policy plus stream receipt validation.
- **Mandatory Post-Run Settings Authority Verification**: Byte-for-byte post-run identity of `settings.json` vs. the pre-launch hash is mandatory acceptance evidence recorded in `POSTFLIGHT_SETTINGS_AUTHORITY.json`. Immediately after AGY returns and `USERPROFILE` is restored, the controller hashes `settings.json`. A mismatch is classified as `RED` by the controller even if AGY native exit is zero and the stream validator otherwise passes (`GREEN`). The controller never rewrites or repairs settings after AGY exits.
- **Stable Manifest Array Schema**: Manifest collection fields (`writable_paths`, `allowed_commands`, `protected_paths`, `mandatory_protected_paths`) are strictly serialized as JSON arrays for zero, one, and multiple entries.
- **Safe Introspection Tool**: `list_permissions` is recognized as a safe, parameterless introspection tool. If called with parameters, it is rejected with `FORBIDDEN_OR_UNKNOWN_TOOL`.

### 3. Prompt Transport, Pinning & Permission Contract
- **Caller Prompt Pinning**: The controller requires mandatory `-ExpectedPromptSha256` (64 hex characters). The prompt file exact bytes are hashed with SHA-256 before profile generation, continuity initialization, or AGY execution. Mismatches fail closed before launch.
- **Automatic Prompt Protection**: The resolved `PromptFile` is automatically combined with caller `ProtectedPaths` and passed to `New-AgyExecutorProfile.ps1`. The prompt file is bound in manifest `protected_paths` and derived as both a denied read root and denied write root.
- **Workplan Location**: File-backed workplans must be located inside an explicitly readable root (such as the dedicated worktree).
- **Controller Transport**: Exact prompt bytes are transported through `-p` by the controller script.
- **No Read Widening**: Never widen `WorkspaceRoot` read permissions merely to rescue a misplaced prompt outside the workspace.

### 4. Direct Stream Transport & Output Separation
- **Distinct Protected Receipt Paths**:
  - `stream.jsonl`: Native stdout emitted by AGY `--output-format stream-json`.
  - `stderr.log`: Native stderr emitted by AGY process execution.
  - `log.txt`: Native diagnostic log written by AGY `--log-file`.
- **Foreground Call Operator Invocation**: AGY is invoked directly with PowerShell's call operator (`&`) and stream redirection (`> stream.jsonl 2> stderr.log`). Process exit code `$LASTEXITCODE` is captured directly from AGY.

### 5. Semantic Acceptance & Adversarial Review Guidance
- **Passing Tests != Acceptance**: A passing worker-authored test is not semantic acceptance.
- **Mandatory Independent Boundary Probes**: Independent review must add at least one adversarial boundary case not proposed by the implementation worker.

## Generator: `New-AgyExecutorProfile.ps1`

PowerShell 7 profile generator creating isolated AGY configuration (`settings.json`) and metadata (`PROFILE_MANIFEST.json`).

### Key Features
- Enforces strict path validation (requires existing `WorkspaceRoot`, rejects filesystem roots, `C:\Projects`, primary `SSTAC-Dashboard` repo root, and `ProfileRoot` located inside `WorkspaceRoot` or traversing junctions).
- Requires mandatory `-WritablePaths` array (must equal or descend from `WorkspaceRoot`).
- Validates every path component of `WorkspaceRoot`, `ProfileRoot`, and `WritablePaths` against `ReparsePoint` attributes to prevent junction/symlink escape.
- Automatically resolves and emits mandatory protected paths (`.git`, all root `.env*` files, `package.json`, etc.) in `permissions.deny` and records them in `PROFILE_MANIFEST.json`.
- Guarantees manifest collections (`writable_paths`, `allowed_commands`, `protected_paths`, `mandatory_protected_paths`) are strictly emitted as JSON arrays.
- Rejects any `WritablePath` that overlaps with any mandatory or caller-supplied protected path.
- Always includes `read_file(<WorkspaceRoot>)` in `permissions.allow`.
- Leaves `toolPermission` absent so AGY 1.1.8 retains its default `request-review` posture.
- Configures explicit mandatory deny rules for dangerous CLI utilities (`git`, `gh`, `supabase`, `docker`, `rm`, `curl`, etc.), URLs, and MCP tools.
- The profile generator restricts `permissions.allow` commands to caller-supplied exact command rules, but note that the production controller currently hard-rejects any nonempty `AllowedCommands` input until a real sandbox canary is accepted.

## Autonomous Worker Controller: `Invoke-AgyAutonomousWorker.ps1`

PowerShell 7 one-command foreground launcher executing tracked AGY 1.1.8 worker runs.

### Key Controller Contract Features
- **Strict Parameter Pinning**: Rejects runs unless AGY version is exactly `1.1.8`, model is `gemini-3.1-pro-high`, effort is `high`, baseline HEAD matches expected commit, branch matches expected branch, and prompt SHA-256 matches expected hash.
- **Validator Preflight Probe**: Resolves `NodeExecutable` (path or command) and the tracked validator script (`validate-agy-stream.mjs`) to existing non-reparse-point files, probes Node version, and executes a bounded preflight syntax check (`node --check validate-agy-stream.mjs`) prior to profile generation and worker launch. Missing Node executable, reparse points, missing validator script, or syntax check failure fail closed before launch.
- **Git State Verification & Hash-Bound Continuation Contract**: Rejects dirty tracked/staged files, baseline drift, and branch drift prior to launch by default. When continuation is explicitly supplied via `-ExpectedTrackedDirtyPaths` and `-ExpectedTrackedDirtySha256`, the controller enforces an explicit hash-bound continuation contract:
  1. Preserves default fail-closed behavior when continuation inputs are unsupplied.
  2. Always rejects staged index changes.
  3. Requires parallel exact arrays of absolute tracked dirty file paths and expected SHA-256 values.
  4. Validates equal nonzero counts, unique paths (case-insensitively on Windows), valid 64-hex hashes, existing regular files, and paths inside `WorkspaceRoot`.
  5. Requires every expected dirty file to be inside at least one exact `WritablePaths` scope.
  6. Enumerates live tracked unstaged paths from Git and requires exact set equality (extra, missing, deleted, renamed fail closed).
  7. Hashes current bytes on disk and requires exact SHA-256 equality before profile generation and AGY launch.
  8. Records accepted relative paths and hashes in deterministic sorted order in `LAUNCH_CONTRACT.json` under `tracked_dirty_files`.
  9. Mutates no Git state (does not stage, restore, rewrite, or commit).
  10. Keeps baseline HEAD and branch pinning unchanged.
- **Foreground Process Invocation**: Uses PowerShell call operator (`&`) for synchronous foreground execution with stdout and stderr redirection. Contains no forbidden background/detached process APIs (`Start-Process`, `Start-Job`, `System.Diagnostics.Process`, `Tee-Object`, etc.).
- **Environment Isolation & Restoration**: Temporarily sets `USERPROFILE` to the generated profile root during AGY execution and restores the original `USERPROFILE` environment variable in a `finally` block on both GREEN and RED/thrown paths.
- **Independent Manifest & Authority Derivation**: Validates manifest collection types, ordering, counts, absolute paths, `mandatory_protected_paths` modes, and `settings_sha256`. Authority arguments (`allowedReadRoot`, `allowedWriteRoots`, `allowedCommands`, `deniedReadRoots`, `deniedWriteRoots`) are derived strictly from generated `PROFILE_MANIFEST.json`.
- **Durable Receipt Trail**: Generates controller receipts from startup to termination (`RUN_STATE.md`, `COMMAND_LOG.md`, `HEARTBEAT.log`, `RESUME_PROMPT.md`, `PR_MANIFEST.md`, `LAUNCH_CONTRACT.json`, `PROMPT.sha256`, `NATIVE_EXIT.txt`, `VALIDATOR_EXIT.txt`, `verdict.json`, `MANIFEST.sha256`, `stream.jsonl`, `stderr.log`, `log.txt`, `POSTFLIGHT_WORKSPACE_AUTHORITY.json`). `LAUNCH_CONTRACT.json` records the resolved `node_executable`, observed `node_version`, and accepted `tracked_dirty_files`.
- **Fail-Closed Verdict**: Executes the post-run validator using strictly the resolved `NodeExecutable`. Returns success only when AGY native exit code is 0, validator exit code is 0, parsed stream verdict is `GREEN`, and the `POSTFLIGHT_WORKSPACE_AUTHORITY.json` result is a `MATCH`. Note that workspace authority is detection, not OS-level write prevention.

### Example Controller Invocation Shape

```powershell
pwsh -NoLogo -NoProfile -File "tooling/agy/Invoke-AgyAutonomousWorker.ps1" `
  -WorkspaceRoot "<ABSOLUTE_PATH_TO_WORKSPACE>" `
  -PromptFile "<ABSOLUTE_PATH_TO_PROMPT_FILE>" `
  -ExpectedPromptSha256 "<64_HEX_CHAR_HASH>" `
  -ProfileRoot "<ABSOLUTE_PATH_FOR_NEW_PROFILE_ROOT>" `
  -ReceiptRoot "<ABSOLUTE_PATH_FOR_NEW_RECEIPT_ROOT>" `
  -WritablePaths @("<ABSOLUTE_PATH_TO_WRITABLE_DIRECTORY>") `
  -ExpectedTrackedDirtyPaths @("<ABSOLUTE_PATH_TO_DIRTY_FILE>") `
  -ExpectedTrackedDirtySha256 @("<64_HEX_CHAR_HASH>") `
  -ExpectedBaselineHead "<40_HEX_CHAR_COMMIT_HASH>" `
  -ExpectedBranch "<CURRENT_BRANCH_NAME>" `
  -ExpectedAgyVersion "1.1.8" `
  -ExpectedModel "gemini-3.1-pro-high" `
  -ExpectedEffort "high" `
  -PrintTimeout "<DURATION_STRING>"
```

## Validator: `validate-agy-stream.mjs`

Dependency-free Node.js module and CLI utility for validating AGY stream JSONL logs.

### Validation Criteria (Fail-Closed)
Returns status `RED` with machine-readable reason codes if any of the following occur:
- `NATIVE_EXIT_CODE_MISSING`: Exit code argument absent, null, or empty.
- `NATIVE_EXIT_CODE_INVALID`: Exit code argument is not an integer.
- `NONZERO_EXIT_CODE`: Native process exit code is non-zero.
- `STDERR_MISSING`: Stderr path is missing, empty, or unreadable.
- `STDERR_ANOMALY`: Stderr contains auto-denial, permission denied, timeout, cancellation, or crash tracebacks.
- `MALFORMED_JSON`: Stream file contains malformed or unparseable JSON lines.
- `INIT_EVENT_MISSING_OR_INVALID`: Missing, duplicate, or misplaced `init` event.
- `INIT_MODEL_MISMATCH`: Absent, empty, or non-matching expected model.
- `INIT_CWD_MISMATCH`: Working directory does not match expected value.
- `INIT_PERMISSION_MODE_INVALID`: Init permission mode is not `request-review`.
- `CONVERSATION_ID_MISSING`: Absent or empty `conversation_id`.
- `CONVERSATION_ID_MISMATCH`: Result or tool step `conversation_id` does not match init `conversation_id`.
- `INVALID_TOOL_LIFECYCLE`: Tool lifecycle violation.
- `TOOL_ERROR`: Any executed tool step ended in `ERROR`.
- `TOOL_ACTIVE_AT_EOF`: Any tool invocation remained unresolved (`ACTIVE`) at stream end.
- `READ_PATH_DENIED`: An executed read tool accessed a denied path.
- `WRITE_PATH_DENIED`: An executed write tool accessed a denied path.
- `READ_PATH_OUTSIDE_SCOPE`: An executed read tool accessed a path outside allowed read root.
- `WRITE_PATH_OUTSIDE_SCOPE`: An executed write tool accessed a path outside allowed write roots.
- `UNAPPROVED_COMMAND`: An executed `run_command` used an unapproved command line.
- `FORBIDDEN_OR_UNKNOWN_TOOL`: Invocation of forbidden tools or `list_permissions` called with parameters.
- `TERMINAL_RESULT_INVALID` / `TERMINAL_STATUS_MISMATCH` / `TERMINAL_RESPONSE_EMPTY`: Missing/duplicate/misplaced result event, status mismatch, or empty response text.

## Testing

Deterministic unit tests using Node.js test runner (`node:test`). The test runner is authoritative for current counts.

> [!NOTE]
> **Test Execution**: `npm run test:agy-tooling` is hermetic and creates temporary fixtures. `npm run test:agy-canary` is optional, evidence-driven, and separate.

```bash
# Run all deterministic suites
npm run test:agy-tooling

# Run optional real-AGY canary verification
npm run test:agy-canary
```
